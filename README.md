# memory-game
## 🚀 Инструкция по локальному запуску

Для запуска игры вам не нужно устанавливать дополнительные серверы, пакеты или сторонние библиотеки. Все работает прямо в браузере.

1.  **Клонируйте репозиторий** на свой компьютер.
2.  **Подготовьте медиафайлы:**
3.  **Запустите игру:**
    Просто дважды кликните по файлу `index.html` или перетащите его в окно любого браузера (Chrome, Firefox, Safari, Edge, Opera).

---

## 🎮 Как играть

1.  В начале игры карточки перемешиваются и раздаются рубашкой вверх. На панели отображаются счетчики: `Ходы: 0` и `Пары: 0 из 8`.
2.  Нажимайте на карточки, чтобы перевернуть их. 
3.  Найдите две одинаковые картинки — они останутся открытыми.
4.  Если картинки не совпали, запомните их расположение. Через 1 секунду они закроются.
5.  Найдите все 8 пар, чтобы победить! На экране появится окно с вашим итоговым результатом, а счет автоматически занесется в общую таблицу лидеров.
6.  Хорошей игры!
